# SUPERHOT Takeover

**Terraria** × SUPERHOT · visual · idea by the team

Bring SUPERHOT into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped SUPERHOT into Terraria: white world, red crystal gunmen, and time only moves when you do. Frozen bullets are weirdly beautiful.

## Install

Copy Sigf.tmod into Documents/My Games/Terraria/tModLoader/Mods and enable it in tModLoader's Manage Mods menu. Enter any world: it turns white, red crystal gunmen come for you, and time only runs while you move. Gunmen drop the Hot Katana and Hot Pistol.
